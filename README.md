# Москва Магнат

Мобильная настольная игра про недвижимость Москвы: покупай районы, строй дома и отели, собирай аренду, разори соперников.
Работает в браузере телефона, без сервера.

## Запуск

```bash
npm install
npm run dev      # dev-сервер (откройте адрес Network на телефоне в той же Wi-Fi сети)
npm test         # тесты движка
npm run build    # сборка в dist/
```

## Этапы

- [x] **1. Основа** — Vite + TypeScript, мобильная вёрстка.
- [x] **2. Движок правил** — поле из 40 клеток, кубики и дубли, покупка, аренда, монополии, дома и отели (равномерная застройка, лимит построек), залог, тюрьма, карточки «Шанс» и «Сюрприз», аукцион, обмен, долги и банкротство.
- [x] **3. Игроки** — от 2 до 6 участников, каждый — человек или бот; режим «по очереди на одном телефоне» с экраном передачи хода; боты покупают, торгуются, строят, меняются и выкручиваются из долгов.
- [~] **4. Графика** — 40 SVG-иконок клеток в едином стиле готовы (посмотреть все: `npm run dev` → `/gallery.html`); впереди фишки игроков и иконки интерфейса.
- [ ] **5. Анимации и звук** — 3D-кубики, прыжки фишек, монеты, звуки, вибрация.
- [~] **6. Интерфейс** — экран обмена с подсказкой, согласится ли бот, уже есть; впереди улучшенные окна и настройки.
- [~] **7. Сохранение** — автосохранение партии в браузере уже работает.
- [ ] **8. Публикация** — PWA (иконка на рабочем столе, офлайн) и GitHub Pages.

## Структура

- `src/data` — поле (районы Москвы, цены, аренда) и тексты карточек.
- `src/engine` — правила игры (`game.ts`), бот (`bot.ts`), типы, ГСЧ.
- `src/ui` — интерфейс, стили и иконки клеток (`icons.ts`).
- `tests` — тесты движка, включая 30 полных партий ботов.
