# Москва Магнат

Мобильная настольная игра про недвижимость Москвы: покупай районы, строй дома и отели, собирай аренду, разори соперников.
Работает в браузере телефона, без сервера.

## Запуск

```bash
npm install
npm run dev      # dev-сервер (откройте адрес Network на телефоне в той же Wi-Fi сети)
npm test         # тесты движка
npm run build    # сборка в dist/
```

## Этапы

- [x] **1. Основа** — Vite + TypeScript, мобильная вёрстка.
- [x] **2. Движок правил** — поле из 40 клеток, кубики и дубли, покупка, аренда, монополии, дома и отели (равномерная застройка, лимит построек), залог, тюрьма, карточки «Шанс» и «Сюрприз», аукцион, обмен, долги и банкротство.
- [x] **3. Игроки** — от 2 до 6 участников, каждый — человек или бот; режим «по очереди на одном телефоне» с экраном передачи хода; боты покупают, торгуются, строят, меняются и выкручиваются из долгов.
- [~] **4. Графика** — SVG-иконки в едином стиле: на поле у вокзалов, служб, налогов, карточек и углов, у улиц — в карточке улицы (на поле у улиц название и цена) (посмотреть все: `npm run dev` → `/gallery.html`); 6 фишек игроков (машинка, цилиндр, собака, ракета, кошка, кораблик) металлические, одного цвета; впереди иконки интерфейса и иконка приложения.
- [x] **5. Анимации и звук** — кувырок кубиков, прыжки фишек дугой, летящие монеты и счётчик денег, конфетти при покупке и победе, переворот карточек, встряска при тюрьме; 15 синтезированных звуков (Web Audio, без файлов) и вибрация; настройки звука и вибрации в меню ☰.
- [~] **6. Интерфейс** — новый дизайн по концепту: светлая лавандовая тема, карточки игроков с плашкой «ХОД», карточка текущей клетки в центре поля на фоне карты Москвы, панель действия с фишкой на подставке, нижнее меню (Имущество / Сделки / История); экран обмена с подсказкой, согласится ли бот. Впереди — настройки.
- [~] **7. Сохранение** — автосохранение партии в браузере уже работает.
- [ ] **8. Публикация** — PWA (иконка на рабочем столе, офлайн) и GitHub Pages.

## Структура

- `src/data` — поле (районы Москвы, цены, аренда) и тексты карточек.
- `src/engine` — правила игры (`game.ts`), бот (`bot.ts`), типы, ГСЧ.
- `src/ui` — интерфейс, стили, иконки клеток (`icons.ts`), фишки (`tokens.ts`), звуки (`sound.ts`) и эффекты (`fx.ts`).
- `tests` — тесты движка, включая 30 полных партий ботов.
